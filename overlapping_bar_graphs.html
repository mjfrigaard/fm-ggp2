10  Overlapping bar graphs


Requirements:

✅ a numeric (continuous) variable

✅ a categorical variable

10.1 Description

Overlapping bar graphs display multiple variables on the same graph. Bars overlap instead of being placed side by side. Bars are often made partially transparent to aid visibility. A legend is essential to distinguish between data.

In ggplot2, we can build overlapping bar graphs using the fill argument in geom_bar() or geom_col()

10.2 Set up

PACKAGES:

Install packages.

show/hide 
library(ggplot2)
library(dplyr) # for tibble() and data manipulation
library(tidyr) # for uncount()

DATA:

Friends drew a huge audience every Thursday night in the 90s, but some seasons drew more than others. We’ll simulate the number of viewers (in millions) for the 24 episodes in seasons 1, 3, and 5. Each season gets its own average audience (mean_viewers), tidyr::uncount() creates one row per episode, and rnorm() draws each episode’s audience, rounded to the nearest million. We’ll also flag whether each episode drew 25 million viewers or more (audience). Setting the seed with set.seed() means you’ll get the same 72 episodes every time you run the code below.

show/hide 
set.seed(1994)
friends_episodes <- tibble(
  season = c("Season 1", "Season 3", "Season 5"),
  mean_viewers = c(22, 27, 24)) |>
  tidyr::uncount(24, .id = "episode") |>
  mutate(viewers_m = round(rnorm(n(), mean = mean_viewers, sd = 2.5)),
         audience = if_else(viewers_m >= 25, "25M or more", "Under 25M")) |>
  select(season, episode, viewers_m, audience)
glimpse(friends_episodes)
#> Rows: 72
#> Columns: 4
#> $ season    <chr> "Season 1", "Season 1", "Seaso…

#> $ viewers_m <dbl> 19, 23, 26, 25, 22, 19, 24, 22…

10.3 Distribution

Overlapping bars only overlap when groups share values. Three seasons with very different audiences would sit side by side with no stacking at all, and three seasons with the same audience would stack into a single pile. How much the bars overlap depends on how far apart the seasons’ averages are compared to how much episodes vary within a season. Below we’ll move from the episodes, to a picture, to the formula.

COUNT IT:

Start with the first six episodes of season 1.

show/hide 
head(friends_episodes, 6)

These episodes drew between 19 and 26 million viewers. The summary below shows each season’s mean, standard deviation, and range.

show/hide 
friends_episodes |> 
  group_by(season) |> 
  summarise(
    mean = mean(viewers_m), 
    sd = sd(viewers_m), 
    min = min(viewers_m), 
    max = max(viewers_m))

Each season’s range covers 6 or 7 million viewers, but the means are only 2 to 4 million apart. So the ranges overlap, which is what puts more than one color in the same bar.

DRAW IT:

The overlapping bar graph below stacks the episodes from all three seasons at each audience size. The dashed lines mark the average audience we gave each season in rnorm(). Season 1 sits mostly on the left, season 3 mostly on the right, and season 5 lands in the middle, sharing bars with both.

show/hide 
ggplot(data = friends_episodes, 
    aes(x = viewers_m, fill = season)) + 
  geom_bar() + 
  geom_vline(xintercept = c(22, 27, 24), 
    color = c("#E2231A", "#F2C230", "#3C78D8"), 
    linetype = "dashed", linewidth = 1) + 
  labs(x = "Viewers (millions)", y = "Episodes", fill = "Season")

NAME IT:

Each season’s audience comes from its own normal distribution with a shared standard deviation:

\[ X_{s} \sim \text{Normal}(\mu_s, \sigma = 2.5), \quad \mu_1 = 22, \; \mu_3 = 27, \; \mu_5 = 24 \]

The overlap depends on the distance between two means measured in standard deviations. Season 1 and season 3 are \((27 - 22) / 2.5 = 2\) standard deviations apart, and season 3 and season 5 are only \((27 - 24) / 2.5 = 1.2\) apart. One way to put a number on that overlap is to pick a random episode from each season and ask how often the “weaker” season wins:

\[ P(X_5 > X_3) = \Phi\left(\frac{24 - 27}{2.5\sqrt{2}}\right) \approx 0.20 \]

So a season 5 episode beats a season 3 episode about 20% of the time, while a season 1 episode beats a season 3 episode only about 8% of the time. Try moving the three means in mean_viewers closer together and the bars stack into a single colorful pile.

10.4 Grammar

CODE:

  • Create labels with labs()

  • Initialize the graph with ggplot() and provide data

  • Map viewers_m to the x and season to fill

  • Add the geom_bar() layer

show/hide 
labs_bar_ovrlp <- labs(
  title = "Friends",
  caption = "Simulated data",
  subtitle = "Viewers per episode in three seasons",
  x = "Viewers (millions)",
  y = "Episodes",
  fill = "Season")
ggp2_bar_ovrlp <- ggplot(data = friends_episodes,
          aes(x = viewers_m, fill = season)) +
                geom_bar() 
ggp2_bar_ovrlp + 
  labs_bar_ovrlp

10.5 More info

  • Overlapping bar graphs can also be built with geom_col().

  • geom_bar() has additional options for arranging overlapping bars. We can set the position argument to "dodge" or "dodge2", depending on how we’d like the data displayed.

10.5.1 geom_col()


To build an overlapping bar graph with geom_col(), we need to create a column with the counts for viewers_m and season in the dataset.

  • Create the friends_col data:
show/hide 
friends_col <- friends_episodes |>
    count(season, viewers_m, name = "Episodes")
  • Map the counts to the y axis, viewers_m to the x axis, and season to fill
show/hide 
labs_col_ovrlp <- labs(
  title = "Friends",
  caption = "Simulated data",
  subtitle = "built with 'geom_col()'",
  x = "Viewers (millions)",
  y = "Episodes",
  fill = "Season")
ggp2_col_ovrlp <- ggplot(data = friends_col, 
    mapping = aes(y = Episodes, 
        x = viewers_m, 
        fill = season)) + 
    geom_col()
ggp2_col_ovrlp + 
    labs_col_ovrlp

10.5.2 dodge


  • position = "dodge" preserves the vertical position of a geom while adjusting the horizontal position

  • "dodge" requires the grouping variable to be be specified in the global or ⁠geom_⁠ layer

We’ll use the audience column, which splits episodes into those with 25 million viewers or more and those with fewer.

show/hide 
count(friends_episodes, audience, season)

  • Create labels with labs()

  • Initialize the graph with ggplot() and provide data

  • Map audience to the x and season to group and fill

  • Inside the geom_bar() function, set position to "dodge"

show/hide 
labs_bar_dodge <- labs(
  title = "Friends",
  caption = "Simulated data",
  subtitle = "position = 'dodge'",
  x = "Audience",
  y = "Episodes",
  fill = "Season")
ggp2_bar_dodge <- ggplot(data = friends_episodes,
                    aes(x = audience, 
                        group = season, 
                        fill = season)) +
                    geom_bar(
                        position = "dodge")
ggp2_bar_dodge +
  labs_bar_dodge

10.5.3 dodge2


  • Create labels with labs()

  • Initialize the graph with ggplot() and provide data

  • Map audience to x and season to fill

  • Inside geom_bar(), set position to "dodge2"

  • "dodge2" works without a grouping variable in a layer

  • "dodge2" works with bars and rectangles

  • "dodge2" is useful for arranging graphs with variable widths.

show/hide 
labs_bar_dodge2 <- labs(
  title = "Friends",
  caption = "Simulated data",
  subtitle = "position = 'dodge2'",
  x = "Audience",
  y = "Episodes",
  fill = "Season")
ggp2_bar_dodge2 <- ggplot(data = friends_episodes,
                    aes(x = audience, 
                        fill = season)) +
                    geom_bar(
                        position = "dodge2")
ggp2_bar_dodge2 +
  labs_bar_dodge2
