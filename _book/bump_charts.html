30  Bump charts

This graph is largely complete and just needs final proof reading.


Requirements:

✅ a categorical variable

✅ a numeric (continuous) variable

✅ a numeric (date) variable

30.1 Description

Bump charts show how numerical (ranked) values change over time for different categories (or groups). Differences are represented with connecting lines (along the y axis) that cover the full timescale (along the x axis).

We can build bump charts in ggplot2 with the ggbump package:

30.2 Set up

PACKAGES:

Install packages.

show/hide 
# pak::pak("davidsjoberg/ggbump")
library(ggbump)
library(ggplot2)
library(dplyr) # for data manipulation
library(tidyr) # for expand_grid()

DATA:

The summer of 1999 belonged to boy bands. The Backstreet Boys had Millennium, *NSYNC was a few months away from No Strings Attached, and LFO’s Summer Girls was on every pool deck radio. We’ll simulate 12 weeks of radio spins (the number of times a song was played across a panel of stations) for six boy bands. Each band gets a weekly average (avg_spins) that rises, falls, or holds steady, and rpois() draws each week’s actual spins around that average. Then we rank the bands within each week (rank), with 1 for the most spins. Setting the seed with set.seed() means you’ll get the same 72 band weeks every time you run the code below.

show/hide 
set.seed(1999)
boy_bands <- expand_grid(
  week = 1:12,
  band = c("Backstreet Boys", "*NSYNC", "98 Degrees",
           "Boyz II Men", "LFO", "Hanson")) |>
  mutate(
    band = factor(band, levels = unique(band)),
    week_of = as.Date("1999-06-05") + 7 * (week - 1),
    avg_spins = case_when(
      band == "Backstreet Boys" ~ 420 - 8 * (week - 1),
      band == "*NSYNC" ~ 300 + 15 * (week - 1),
      band == "98 Degrees" ~ 330,
      band == "Boyz II Men" ~ 360 - 5 * (week - 1),
      band == "LFO" ~ 200 + 20 * (week - 1),
      band == "Hanson" ~ 280 - 10 * (week - 1)),
    spins = rpois(n(), lambda = avg_spins)) |>
  group_by(week) |>
  mutate(rank = rank(-spins, ties.method = "random")) |>
  ungroup()
glimpse(boy_bands)
#> Rows: 72
#> Columns: 6
#> $ week      <int> 1, 1, 1, 1, 1, 1, 2, 2, 2, 2, …

30.3 Distribution

A bump chart throws away the raw numbers and keeps only the order. That makes it easy to see who passed whom, but it also hides how close the race was. When two bands have similar spins, random week to week noise can swap their ranks even though nothing real changed. Below we’ll move from the spins, to a picture, to the formula.

COUNT IT:

Start with the first week.

show/hide 
boy_bands |>
  filter(week == 1) |>
  select(band, avg_spins, spins, rank) |>
  arrange(rank)

Every band landed within a few dozen spins of its average, and the ranks match the order of the averages. Below we count how many times each band changed rank from one week to the next.

show/hide 
rank_changes <- boy_bands |>
  group_by(band) |>
  summarise(rank_changes = sum(rank != lag(rank), na.rm = TRUE),
            first_rank = first(rank), last_rank = last(rank))
rank_changes

*NSYNC and LFO climb because their averages climb, and the Backstreet Boys and Hanson slide because theirs slide. But 98 Degrees changes rank 7 times even though its average never changes.

DRAW IT:

The graph below plots the raw spins for 98 Degrees and Boyz II Men. The ribbon around each line covers the average plus or minus two standard deviations (more on that below). Wherever the two ribbons overlap, either band could come out ahead in a given week.

show/hide 
two_bands <- boy_bands |>
  filter(band %in% c("98 Degrees", "Boyz II Men"))
ggplot(two_bands, aes(x = week_of, color = band, fill = band)) +
  geom_ribbon(aes(ymin = avg_spins - 2 * sqrt(avg_spins),
                  ymax = avg_spins + 2 * sqrt(avg_spins)),
              alpha = 1 / 4, color = NA) +
  geom_line(aes(y = spins), linewidth = 1) +
  geom_point(aes(y = spins), size = 2) +
  scale_color_manual(values = c("98 Degrees" = "#F2C14E", "Boyz II Men" = "#B79CFF"),
                     aesthetics = c("color", "fill")) +
  labs(x = "Week of", y = "Spins", color = "Band", fill = "Band")

The ribbons overlap for the whole summer, which is why these two bands trade places in the bump chart.

NAME IT:

Each band’s weekly spins follow a Poisson distribution with its own average for that week (\(\lambda\)):

\[ \text{spins}_{b,w} \sim \text{Poisson}(\lambda_{b,w}) \]

A Poisson count has a standard deviation of \(\sqrt{\lambda}\), so a band averaging 330 spins wobbles by about \(\sqrt{330} \approx 18\) spins a week (that’s the ribbon width above). The gap between two bands is approximately normal, with a mean of \(\lambda_1 - \lambda_2\) and a standard deviation of \(\sqrt{\lambda_1 + \lambda_2}\). In week one, Boyz II Men averages 360 spins and 98 Degrees averages 330, so the chance that 98 Degrees comes out ahead anyway is:

\[ P(\text{swap}) \approx \Phi\left(\frac{-(360 - 330)}{\sqrt{360 + 330}}\right) \approx 0.13 \]

By week seven, both bands average 330 spins and the chance is a coin flip (0.5). Rank charts are great for showing who’s on top, but small gaps between ranks are often just Poisson noise. Try making the averages twice as far apart in case_when() and the bump chart gets a lot calmer.

30.4 Grammar

CODE:

  • Create labels with labs()

  • Map week_of to the x, rank to the y, and band to color

  • Add ggbump::geom_bump() and set linewidth to 2

  • Flip the y axis with scale_y_reverse() so rank 1 is on top

  • Move legend to bottom with theme(legend.position = "bottom")

show/hide 
labs_bump <- labs(title = "Boy band radio spins",
  caption = "Simulated data",
  subtitle = "Weekly rank, summer 1999",
  x = "Week of", y = "Rank",
  color = "Band")
ggp2_bump <- ggplot(boy_bands,
    aes(x = week_of,
      y = rank,
      color = band)) +
    ggbump::geom_bump(linewidth = 2) +
    scale_y_reverse(breaks = 1:6) +
    theme(legend.position = "bottom")

ggp2_bump +
  labs_bump
