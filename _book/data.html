Appendix A — Data

Every graph in this book is built from simulated data. Each chapter creates its own dataset in a code chunk you can see and run, using base R’s random number functions (rnorm(), rpois(), rgamma(), sample(), and friends) or the faux package. None of the examples depend on a data package, and each dataset has a late 90s theme to match the chapter’s graph.

A.1 Why simulated data?

I’ve found that simulated data solves two problems at once. First, it’s completely reproducible. Each chapter calls set.seed() (usually with a 90s year), so you’ll get the same values I did every time you run the code. Second, we know the truth behind every dataset. When we simulate 300 Pokémon starters with known probabilities, we can check how close the counts land, and that’s exactly what the Distribution section in each chapter does:

  • COUNT IT: look at the first few rows and summarize the values

  • DRAW IT: sketch the values in a simple picture that connects them to the chapter’s graph

  • NAME IT: name the distribution behind the data and walk through its formula

Real data ‘caught in the wild’ has its place, but you can’t look up the distribution it came from. Simulated data keeps the graph, the numbers, and the formula in sync, so you can see why a graph looks the way it does. Try changing an argument (a mean, a probability, or a sample size) in any chapter and re-run the code to see how the graph responds.
