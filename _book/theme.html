Appendix C — Theme

Every chapter in this book has its own late 90s ggplot2 theme to match its simulated data (Game Boy greens for the Pokémon starters, silver comic book cans for OK Soda, and so on). The themes and the small helpers the book uses live in the fmggp2 package, so every chapter loads the same tested code.

C.1 Installing fmggp2

Install the development version of fmggp2 from GitHub:

show/hide 
# install.packages("pak")
pak::pak("mjfrigaard/fmggp2")

C.2 Using a theme

Each chapter sets its theme once in the setup chunk with ggplot2::theme_set(), so every graph in the chapter picks it up and we don’t have to add the theme to each plot:

show/hide 
ggplot2::theme_set(fmggp2::theme_gameboy(base_size = 14))

We can also add a theme to a single graph like any other ggplot2 theme. Below we simulate a few home PCs from 1998 and add theme_netscape():

show/hide 
set.seed(1998)
home_pcs <- tibble(mhz = runif(60, min = 200, max = 450)) |>
  mutate(price = 600 + 3 * mhz + rnorm(60, mean = 0, sd = 150))
ggplot(home_pcs, aes(x = mhz, y = price)) +
  geom_point() +
  labs(title = "Home PCs in 1998", caption = "Simulated data",
       x = "Processor speed (MHz)", y = "Price (USD)") +
  fmggp2::theme_netscape(base_size = 14)

C.3 What the themes set

The 90s themes are built on ggplot2::theme_bw() and use features from ggplot2 4.0, so a single theme can control much more than the background and fonts:

  • Colors: the plot background, the frame around the plot, the panel, and the grid lines all come from a palette sampled from the 90s reference.

  • Fonts: most themes pair Arial body text with a title display font that fits the reference (Impact for Blockbuster, Gill Sans for NetWare, Comic Sans for GeoCities).

  • Discrete palettes: palette.fill.discrete and palette.colour.discrete set the colors for categorical variables, so mapping a variable to fill or color uses the theme’s colors automatically.

  • Continuous palettes: four themes (theme_freshprince(), theme_bopit(), theme_geocities(), and theme_surge()) also set palette.fill.continuous, which colors heatmaps, 2D histograms, and hexagon bins.

  • Default geoms: element_geom() sets the default fill, colour, and font for layers like geom_bar() and geom_point(), so a graph with no color mapping still matches the theme.

TipOrdered factors

Ordered factors use the viridis scale by default, which overrides the theme’s discrete palette. If a graph doesn’t pick up the theme colors, check whether the variable mapped to fill or color is an ordered factor (for example, the output of lubridate::wday(label = TRUE)). If it is, convert it with factor(x, ordered = FALSE).

C.4 Fonts

The display fonts are system fonts that ship with macOS. Each theme registers its fonts with sysfonts::font_add(). When a font file can’t be found (on Linux or Windows, for example), the theme falls back to "sans" so the graphs still render. You can also pass any font family you’ve registered yourself:

show/hide 
fmggp2::theme_oksoda(base_family = "sans", title_family = "sans")
fmggp2::theme_batman(base_family = "sans", title_family = "sans")

The showtext package draws the registered fonts in the graphs, so each chapter calls showtext::showtext_auto() in its setup chunk. The themes vignette lists every theme’s fonts.

C.6 The original book theme

The pages outside the chapters (like this appendix) use fmggp2::theme_fmggp2(), the original custom theme for this book. It combines elements from ggplot2::theme_minimal() and ggplot2::theme_void() with the Ubuntu font, thin light gray grid lines, and no axis ticks. You can view the source code here.
