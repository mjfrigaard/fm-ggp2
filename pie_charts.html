17  Pie charts

This graph is largely complete and just needs final proof reading.


Requirements:

✅ a categorical variable

17.1 Description

“In general, pie charts work well when the goal is to emphasize simple fractions, such as one-half, one-third, or one-quarter.”

“They also work well when we have very small datasets.” - Claus O. Wilke, Fundamentals of Data Visualization (2019)

Pie-charts are ideal for comparing the proportions of categorical variable values, and we can build pie-charts using the ggpubr package.

17.2 Set up

PACKAGES:

Install packages.

show/hide 
install.packages("ggpubr")
library(ggpubr)
library(ggplot2)
library(dplyr) # for tibble() and data manipulation

DATA:

Every 90s school year started with a new Trapper Keeper, and the Lisa Frank designs (rainbow leopards, unicorns, dolphins, and pandas in neon colors) were the ones everyone wanted. We’ll simulate the designs of 200 Trapper Keepers sold at a school supply store with sample(). The probabilities are simple fractions on purpose: one half, one quarter, one eighth, and one eighth. Then we count each design (cnt) and convert the counts to proportions (perc). Setting the seed with set.seed() means you’ll get the same 200 Trapper Keepers every time you run the code below.

show/hide 
set.seed(1993)
trapper_keepers <- tibble(
  keeper_id = 1:200,
  design = sample(c("Rainbow leopards", "Unicorns", "Dolphins", "Pandas"),
    size = 200, replace = TRUE, prob = c(1/2, 1/4, 1/8, 1/8)))
keeper_pie <- trapper_keepers |>
  count(design, name = "cnt") |>
  mutate(
    perc = cnt / sum(cnt),
    design = factor(design,
      levels = c("Rainbow leopards", "Unicorns", "Dolphins", "Pandas"))) |>
  arrange(design)
glimpse(keeper_pie)
#> Rows: 4
#> Columns: 3
#> $ design <fct> Rainbow leopards, Unicorns, Dolph…
#> $ cnt    <int> 98, 49, 23, 30
#> $ perc   <dbl> 0.490, 0.245, 0.115, 0.150

17.3 Distribution

A pie chart is a whole cut into slices, so it only makes sense when the slices add up to one thing (here, 200 Trapper Keepers). Pie charts are easiest to read when the slices are simple fractions, and because we chose those fractions in sample(), we know what each slice should look like. Below we’ll move from the Trapper Keepers, to a picture, to the formula.

COUNT IT:

Start with the first ten Trapper Keepers.

show/hide 
head(trapper_keepers$design, 10)
#>  [1] "Rainbow leopards" "Rainbow leopards"
#>  [3] "Rainbow leopards" "Unicorns"        
#>  [5] "Unicorns"         "Unicorns"        
#>  [7] "Rainbow leopards" "Rainbow leopards"
#>  [9] "Pandas"           "Rainbow leopards"

Counting all 200 and comparing each count to the count we’d expect (200 times each fraction) shows how close the simulation lands.

show/hide 
keeper_pie |>
  mutate(expected = 200 * c(1/2, 1/4, 1/8, 1/8))

DRAW IT:

A bar model lays the 200 Trapper Keepers out in a line. Rainbow leopards fill about half the bar, unicorns about a quarter, and dolphins and pandas split the last quarter.

show/hide 
ggplot(data = keeper_pie, aes(x = cnt, y = "200 Trapper Keepers",
    fill = design)) +
  geom_col(position = position_stack(reverse = TRUE)) +
  geom_text(aes(label = cnt), color = "#3D0066",
    position = position_stack(vjust = 0.5, reverse = TRUE)) +
  labs(x = "Trapper Keepers", y = NULL, fill = "Design")

A pie chart bends the same bar into a circle. Below, the pie on the left uses the exact fractions from sample(), and the pie on the right uses our simulated counts. The leopard slice covers about half the circle in both, and the unicorn slice covers about a quarter.

show/hide 
expected_pie <- keeper_pie |>
  mutate(perc = c(1/2, 1/4, 1/8, 1/8))
ggpubr::ggpie(expected_pie, x = "perc",
    label = paste0(round(100 * expected_pie$perc, 1), "%"),
    lab.pos = "in", lab.font = "#3D0066",
    fill = "design", color = "white") +
  labs(title = "Expected", fill = NULL) +
  pie_theme

ggpubr::ggpie(keeper_pie, x = "perc",
    label = paste0(round(100 * keeper_pie$perc, 1), "%"),
    lab.pos = "in", lab.font = "#3D0066",
    fill = "design", color = "white") +
  labs(title = "Simulated", fill = NULL) +
  pie_theme

NAME IT:

Each Trapper Keeper is one draw from four designs, so the four counts follow a multinomial distribution:

\[ (N_{\text{leopards}}, N_{\text{unicorns}}, N_{\text{dolphins}}, N_{\text{pandas}}) \sim \text{Multinomial}\left(200, \; \left(\tfrac{1}{2}, \tfrac{1}{4}, \tfrac{1}{8}, \tfrac{1}{8}\right)\right) \]

A slice’s angle is its share of the 360 degrees in the circle: \(\tfrac{1}{2}\) is 180 degrees, \(\tfrac{1}{4}\) is 90 degrees, and each \(\tfrac{1}{8}\) is 45 degrees. Simple fractions like these line up with the “clock positions” our eyes already know (half past, quarter past), which is why pie charts work best with them.

Each simulated share wobbles around its fraction by about \(\sqrt{p(1 - p) / 200}\): about 3.5 percentage points for the leopard slice and 2.3 points for the dolphin and panda slices. That’s why our slices are close to the expected ones but not exact. Try changing size = 200 to size = 20 in sample() and the slices drift much further from the simple fractions.

17.4 Grammar

CODE:

  • Create the slice labels (pie_labels) with paste0()

  • ggpie() applies its own theme, so create pie_theme to add the book theme back (and remove the axis text, ticks, and grid lines)

  • Create labels with labs()

  • Assign the data to ggpubr::ggpie()

  • Assign "perc" to x

  • Assign pie_labels to label

  • Assign "in" to lab.pos

  • Assign a dark color to lab.font and "white" to color

  • Assign "design" to fill

  • Add pie_theme (which also moves the legend to the bottom)

show/hide 
pie_labels <- paste0(round(100 * keeper_pie$perc), "%")
pie_theme <- fmggp2::theme_lisafrank(base_size = 14) +
  theme(axis.text = element_blank(), axis.title = element_blank(),
        axis.ticks = element_blank(), panel.grid.major = element_blank(),
        legend.position = "bottom")
labs_pie <- labs(
  title = "Trapper Keepers",
  caption = "Simulated data",
  subtitle = "Lisa Frank designs sold",
  fill = NULL)

ggp2_pie <- ggpubr::ggpie(keeper_pie,
          x = "perc", label = pie_labels,
          lab.pos = "in", lab.font = "#3D0066",
          fill = "design", color = "white") +
    pie_theme

ggp2_pie +
  labs_pie
