14  Diverging bar graphs

This graph is largely complete and just needs final proof reading.


Requirements:

✅ a categorical variable

✅ a numeric (continuous) variable

14.1 Description

If you have two proportions that contain positive and negative values, consider using diverging bars with geom_bar().

Unlike a standard or stacked bar graphs, diverging bar graphs display positive and negative quantities on both sides of a reference or baseline value (zero in this example). Color, length and position are used to compare the quantities across categorical levels (and within variable values).

14.1.1 Horizontal bars

For example, we can use the length of the bar from the reference line to compare Orbitz’s share across all weeks (i.e., comparing the magenta bars to each other).

14.1.2 Vertical bars

We can also compare Surge vs. Orbitz within each week (i.e., compare the gold vs. magenta bars to each other within each week).

14.2 Set up

PACKAGES:

Install packages.

show/hide 
library(ggplot2)
library(dplyr) # for data manipulation
library(tidyr) # for uncount()

DATA:

Orbitz hit shelves in 1997 with colorful gel balls floating in a clear, fruity drink. Kids bought it once to see the balls, and then most of them went back to Surge. We’ll simulate a weekly lunchroom survey of 400 kids over the seven weeks after Orbitz arrived, asking which drink they bought that week: Surge, Orbitz, or something else (Other).

Surge’s chance of being picked grows each week as the novelty wears off (p_surge), Orbitz gets what’s left of 80% (p_orbitz), and Other stays at 20%. For each kid, runif() draws a number between 0 and 1, and case_when() turns that number into a choice using the week’s probabilities. Then we keep Surge and Orbitz, calculate each one’s share of the 400 kids, and make Orbitz’s share negative so it points down. Setting the seed with set.seed() means you’ll get the same 2,800 answers every time you run the code below.

show/hide 
set.seed(1993)
lunchroom_survey <- tibble(week = 1:7) |>
  mutate(p_surge = 0.8 * plogis(-2 + 0.6 * (week - 1)),
         p_orbitz = 0.8 - p_surge) |>
  tidyr::uncount(400, .id = "kid") |>
  mutate(u = runif(n()),
         choice = case_when(u < p_surge ~ "Surge",
                            u < p_surge + p_orbitz ~ "Orbitz",
                            TRUE ~ "Other")) |>
  select(week, kid, choice)
orbitz_diverg <- lunchroom_survey |>
  filter(choice != "Other") |>
  count(week, choice) |>
  mutate(share = n / 400,
         share = if_else(choice == "Orbitz", -share, share),
         choice = factor(choice, levels = c("Surge", "Orbitz")),
         week = factor(week))
glimpse(orbitz_diverg)

14.3 Distribution

A diverging bar graph puts two shares back to back, so the question it answers is “how do these two groups trade places?” Here, every kid picks exactly one drink each week, so a gain for Surge has to come from somewhere. Below we’ll move from the households, to a picture, to the formula.

COUNT IT:

Start with the first ten kids surveyed in week 1.

show/hide 
head(lunchroom_survey$choice, 10)
#>  [1] "Orbitz" "Surge"  "Orbitz" "Orbitz" "Orbitz"
#>  [6] "Orbitz" "Orbitz" "Orbitz" "Other"  "Surge"

Seven of these ten kids bought Orbitz, two bought Surge, and one bought something else. Counting every kid in every week shows the trade: Orbitz’s count falls each week while Surge’s climbs, and Other stays between about 60 and 100.

show/hide 
lunchroom_survey |>
  count(week, choice) |>
  tidyr::pivot_wider(names_from = choice, values_from = n)

DRAW IT:

A bar model shows each week’s 400 kids as one bar split three ways. Reading down the weeks, the Surge part grows, the Orbitz part shrinks, and the Other part barely moves.

show/hide 
lunchroom_survey |>
  count(week, choice) |>
  mutate(choice = factor(choice,
    levels = c("Surge", "Orbitz", "Other"))) |>
  ggplot(aes(x = n, y = factor(week), fill = choice)) +
  geom_col(position = position_stack(reverse = TRUE)) +
  labs(x = "Kids", y = "Week", fill = "Drink")

The diverging bar graph below takes the Surge and Orbitz parts of each bar and points them in opposite directions from zero. The points mark the shares we built into the simulation. The two bars are the same length somewhere between weeks 4 and 5, which is where the two drinks traded places.

show/hide 
expected_shares <- tibble(week = 1:7) |>
  mutate(Surge = 0.8 * plogis(-2 + 0.6 * (week - 1)),
         Orbitz = -(0.8 - Surge),
         week = factor(week)) |>
  tidyr::pivot_longer(-week, names_to = "choice", values_to = "share")

ggplot(data = orbitz_diverg, aes(x = week, y = share)) +
  geom_bar(aes(fill = choice), stat = "identity", width = .5) +
  geom_point(data = expected_shares, size = 2.5) +
  geom_hline(yintercept = 0) +
  scale_y_continuous(limits = c(-1, 1), labels = scales::percent) +
  labs(x = "Week", y = "Share of kids", fill = "Drink")

NAME IT:

Each kid’s answer is a single draw from three choices, so each week’s counts follow a multinomial distribution:

\[ (N_{\text{Surge}}, N_{\text{Orbitz}}, N_{\text{Other}}) \sim \text{Multinomial}\left(400, \; (p_t, \; 0.8 - p_t, \; 0.2)\right) \]

\[ p_t = 0.8 \times \text{logistic}\left(-2 + 0.6\,(t - 1)\right) \]

The logistic function (plogis()) gives Surge’s share an S shaped climb: slow at first, fastest in the middle, then leveling off. Surge and Orbitz split the same 80%, so their bars are the same length when \(p_t = 0.4\). That happens when \(-2 + 0.6\,(t - 1) = 0\), or \(t \approx 4.3\).

Each simulated share wobbles around its point by about \(\sqrt{p(1 - p) / 400}\), which is never more than 2.5 percentage points. That’s why the bars land so close to the points. Try changing the 0.6 in plogis() and the crossover moves earlier (larger values) or later (smaller values).

14.4 Grammar

CODE:

  • Create labels with labs()

  • Initialize the graph with ggplot() and provide data

  • Map the week to the x and share to the y

  • Insidegeom_bar()

    • map choice to fill

    • use stat = "identity" and width = .5

  • Add scale_y_continuous() to manually set the limits and format the axis with scales::percent

show/hide 
labs_geom_bar_diverg <- labs(
  title = "Orbitz vs. Surge",
  caption = "Simulated data",
  subtitle = "Drink 400 kids bought each week in 1997",
  x = "Week",
  y = "Share of kids",
  fill = "Drink")
ggp2_bars_diverg <- ggplot(
  data = orbitz_diverg,
    aes(x = week, y = share)) +
  geom_bar(aes(fill = choice),
    stat = "identity", width = .5) +
  scale_y_continuous(limits = c(-1, 1),
    labels = scales::percent)

ggp2_bars_diverg +
  labs_geom_bar_diverg

14.5 More info

For vertically arranged bars, we switch the x and y axis variables.

14.5.1 Vertically arranged bars


  • Create labels with labs()

  • Map the share to the x and week to the y

  • Inside geom_bar()

    • map choice to fill

    • use stat = "identity" and width = .5

  • Add scale_x_continuous() to manually set the limits and format the axis with scales::percent

show/hide 
labs_geom_bar_diverg_vert <- labs(
  title = "Orbitz vs. Surge",
  caption = "Simulated data",
  subtitle = "Drink 400 kids bought each week in 1997",
  x = "Share of kids",
  y = "Week",
  fill = "Drink")
ggp2_bar_diverg_vert <- ggplot(
  data = orbitz_diverg,
      aes(x = share, y = week)) +
  geom_bar(
      aes(fill = choice),
        stat = "identity", width = .5) +
  scale_x_continuous(limits = c(-1, 1),
        labels = scales::percent)
ggp2_bar_diverg_vert +
  labs_geom_bar_diverg_vert
