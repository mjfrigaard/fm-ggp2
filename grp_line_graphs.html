29  Grouped line graphs

This graph is largely complete and just needs final proof reading.


Requirements:

✅ a numeric (continuous) variable

✅ a numeric (date) variable

✅ at least one categorical variable

29.1 Description

Grouped line graphs use color, line style, and faceting to show group changes over time for a continuous variable across categorical levels.

29.2 Set up

PACKAGES:

Install packages.

show/hide 
library(ggplot2)
library(dplyr) # for tibble() and data manipulation
library(lubridate) # for working with dates

DATA:

Every Saturday night starting in 1992, Nickelodeon kids parked themselves in front of SNICK (Clarissa Explains It All, Are You Afraid of the Dark?, and All That) and the orange couch. We’ll simulate a Nielsen style rating for Nickelodeon for every day from 1993 through 1999. Each night of the week gets its own average (night_avg), with Saturday on top. Two smooth patterns get added to the nightly averages: a trend that rises through the middle of the decade and falls off near the end, and a summer bump when school is out. Then rnorm() adds day to day noise. Setting the seed with set.seed() means you’ll get the same 2,556 days every time you run the code below.

We’ll also create the date variables we need for grouping:

  • day_of_week (a factor from wday(), unordered so the graphs use the theme colors) and day_category ("Weekday" or "Weekend")

  • yr_mnth (the first day of each month) and yr_qtr (the year and quarter)

show/hide 
set.seed(1992)
nick_ratings <- tibble(
  date = seq(as.Date("1993-01-01"), as.Date("1999-12-31"), by = "day")) |>
  mutate(
    year = year(date),
    month = month(date),
    day_of_week = factor(wday(date, label = TRUE), ordered = FALSE),
    day_category = if_else(day_of_week %in% c("Sat", "Sun"),
                           "Weekend", "Weekday"),
    yr_mnth = floor_date(date, unit = "month"),
    yr_qtr = factor(paste0(year, "/0", quarter(date)), ordered = TRUE),
    night_avg = c(Sun = 3.0, Mon = 2.4, Tue = 2.3, Wed = 2.3,
                  Thu = 2.4, Fri = 2.8, Sat = 4.2)[as.character(day_of_week)],
    trend = 0.25 * (year - 1993) - 0.04 * (year - 1993)^2,
    summer = 0.3 * sin(2 * pi * (month - 4) / 12),
    rating = round(rnorm(n(), mean = night_avg + trend + summer,
                         sd = 0.35), 2)) |>
  select(-night_avg, -trend, -summer)
glimpse(nick_ratings)

29.3 Distribution

A grouped line graph rarely plots raw values. It plots an average for each group at each point in time, and averages behave very differently from the values they’re built from. Below we’ll move from the daily ratings, to a picture, to the formula, and see why averaging makes the group differences easy to see.

COUNT IT:

Start with the first week of 1996.

show/hide 
nick_ratings |>
  filter(year == 1996) |>
  select(date, day_of_week, rating) |>
  head(7)

Saturday is the clear winner this week, but the weeknights are close enough that the order could flip next week. Below we count every night in 1996 and calculate the mean and standard deviation for each night of the week.

show/hide 
nick_1996 <- nick_ratings |>
  filter(year == 1996) |>
  group_by(day_of_week) |>
  summarise(n = n(), mean = mean(rating), sd = sd(rating))
nick_1996

Each night of the week shows up 52 or 53 times in a year. The Saturday mean (4.63) is well above the Tuesday mean (2.67), but any single night wanders about 0.4 rating points from its mean.

DRAW IT:

The graph below draws every Tuesday and Saturday rating from 1996 as a thin, faded line, then adds each month’s average as a thick line. The daily lines zig and zag, while the monthly averages are much smoother.

show/hide 
tue_sat_1996 <- nick_ratings |>
  filter(year == 1996, day_of_week %in% c("Tue", "Sat"))
tue_sat_monthly <- tue_sat_1996 |>
  group_by(yr_mnth, day_of_week) |>
  summarise(avg_rating = mean(rating), .groups = "drop")
ggplot() +
  geom_line(data = tue_sat_1996,
            aes(x = date, y = rating, color = day_of_week),
            alpha = 1 / 3) +
  geom_line(data = tue_sat_monthly,
            aes(x = yr_mnth, y = avg_rating, color = day_of_week),
            linewidth = 1.5) +
  labs(x = "1996", y = "Rating", color = "Night")

NAME IT:

Each day’s rating is a draw from a normal distribution centered on that night’s average for that time of year:

\[ \text{rating}_d \sim \text{Normal}\left(\mu_{\text{night}} + \text{trend}_{\text{year}} + \text{summer}_{\text{month}}, \; \sigma = 0.35\right) \]

The standard deviation of an average of \(n\) draws is \(\sigma / \sqrt{n}\) (the standard error). A monthly average of about four Saturdays wobbles by about \(0.35 / \sqrt{4} \approx 0.18\) points, and a yearly average of about 52 Saturdays wobbles by only \(0.35 / \sqrt{52} \approx 0.05\) points. That’s why the yearly avg_rating lines below are so smooth, and why the gap between weekdays and weekends stands out. The sd column in COUNT IT is a little larger than 0.35 because it also includes the summer bump. Try changing sd = 0.35 to sd = 1 and watch the daily lines in DRAW IT turn into a tangle while the yearly lines barely move.

CODE:

  • Map year to the x, avg_rating to the y, and day_category to group

  • Add the geom_line() layer and map day_category to color (inside aes())

labs_line_graph <- labs(title = "Nickelodeon ratings",
                        caption = "Simulated data",
                        subtitle = "1993-1999",
                        y = "Average rating",
                        x = "Year",
                        color = "Day Category")

ggp2_line <- ggplot(data = avg_rating_day_cat_yr,
       mapping = aes(x = year,
                     y = avg_rating,
                     group = day_category)) +
    geom_line(aes(color = day_category))

29.5 More info

Line graphs are great for displaying relationships across variables with multiple groups (or levels). We can also use facets for multiple comparisons (i.e., small multiples).

29.5.1 Groups

In the previous graph, we can see the ratings peak around 1996 or 1997.

  • Then calculate the average rating as avg_rating

29.5.3 alpha & linewidth

Line styles are an excellent tool for highlighting or emphasizing certain lines over others.

  • We’ll start by creating a line graph layer for Monday ("Mon"), Thursday ("Thu"), and Friday ("Fri") adjusting the opacity with alpha.
show/hide 
ggp2_line_mon_thu_fri <-
    ggplot(data = filter(avg_rating_dow_mnth,
        day_of_week %in% c("Mon", "Thu", "Fri"))) +
    geom_line(
        aes(x = yr_mnth,
            y = avg_rating,
            group = day_of_week,
            color = day_of_week),
        alpha = 1 / 4,
        linewidth = 0.85)
# layer 1
ggp2_line_mon_thu_fri +
    labs_line_styles +
    theme(legend.position = "top")

29.5.5 Color palettes

  • Add geom_line() for Tuesday and Wednesday, and set the colors manually with scale_color_manual() (below we use a named vector of SNICK colors).

  • We also manually set the legend order by supplying the original factor levels to the breaks argument.

show/hide 
# original factor levels
lev_order <- levels(avg_rating_dow_mnth$day_of_week)
# SNICK colors
snick_pal <- c(Sun = "#FF5FA2", Mon = "#29B6F6", Tue = "#8CC63F",
               Wed = "#FFD200", Thu = "#B07CE8", Fri = "#F4F1FA",
               Sat = "#F57D0D")
# layer 3
ggp2_line_pal_d <- ggp2_line_sat_sun +
    # add line
    geom_line(data = filter(avg_rating_dow_mnth,
            day_of_week %in% c("Tue", "Wed")),
        aes(x = yr_mnth,
            y = avg_rating,
            group = day_of_week,
            color = day_of_week),
        linewidth = 1.25) +
    # add palette
    scale_color_manual(
        breaks = lev_order,
        # original factor levels
        values = snick_pal)
# three layers
ggp2_line_pal_d +
    # labels
    labs_line_styles +
    # legend position
    theme(legend.position = "top")

Changing the look of the lines is a great way to highlight or emphasize some lines over others.

29.5.6 Labels

We’ll use labels to display the highest daily rating and the highest monthly average rating for a few nights of the week.

  • To accomplish this, we’re going to create two small tables of labels, label_max_dow and label_max_avg_dow, that we’ll use to label the maximum values.

  • Each has a row for every night of the week (label_max_dow can have more if two nights tie for the max) and a label variable (lbl) which we can use with geom_label().

show/hide 
label_max_dow <- nick_ratings |>
    group_by(day_of_week) |>
    summarise(max_rating = max(rating)) |>
    ungroup() |>
    inner_join(y = nick_ratings,
        by = c("max_rating" = "rating", "day_of_week")) |>
    mutate(lbl = paste0(day_of_week,
        " (", date, "), max rating = ", max_rating)) |>
    select(day_of_week, yr_mnth, max_rating, lbl)

arrange(label_max_dow, desc(max_rating)) |>
    slice(1:2)
show/hide 
label_max_avg_dow <- avg_rating_dow_mnth |>
    # group by sun-sat
    group_by(day_of_week) |>
    # get max avg
    slice_max(order_by = avg_rating, n = 1) |>
    # ungroup
    ungroup() |>
    rename(max_avg_rating = avg_rating) |>
    mutate(lbl = paste0(day_of_week,
        ": max avg rating = ", round(max_avg_rating, 2)))
arrange(label_max_avg_dow, desc(max_avg_rating)) |>
    slice(1:2)

29.5.7 Facets

Finally, we can use facets to view each of the line graphs separately (or small multiples).

  • We’ll create a dataset with the daily ratings between 1998-07-01 and 1999-12-31 and store it as daily_ratings_9899
show/hide 
daily_ratings_9899 <- nick_ratings |>
    filter(date >= as.Date("1998-07-01")) |>
    select(date, day_category, day_of_week, rating)
glimpse(daily_ratings_9899)
#> Rows: 549
#> Columns: 4
#> $ date         <date> 1998-07-01, 1998-07-02, 19…
#> $ day_category <chr> "Weekday", "Weekday", "Week…
#> $ day_of_week  <fct> Wed, Thu, Fri, Sat, Sun, Mo…
#> $ rating       <dbl> 3.11, 2.48, 3.68, 4.25, 3.3…
  • Using facet_wrap() with a single categorical variable (. ~ var) will create a plot for each discrete level, while facet_grid() will create a level-by-level grid (specified as var ~ var).

# labels
labs_line_graph_facet_wrap <- labs(
    title = "Nickelodeon ratings",

        " and ",
        max(daily_ratings_9899$date)

    y = "Rating",
    x = "Date",
    color = "Day of Week"
)
# layer
ggp2_line_facet_wrap <- ggplot(data = daily_ratings_9899,
    mapping = aes(x = date,
        y = rating,
        group = day_of_week)) +
    geom_line(aes(color = day_of_week)) +
    scale_color_manual(values = snick_pal) +
    scale_y_continuous(breaks = c(2, 3, 4, 5)) +
    scale_x_date(date_breaks = "1 year",
        date_labels = "%Y") +
    facet_wrap(day_of_week ~ ., shrink = TRUE)

    labs_line_graph_facet_wrap +
    theme(legend.position = "top")
